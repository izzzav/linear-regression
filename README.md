# Линейная регрессия и регуляризация: реализация с нуля

Учебно-исследовательский проект, в котором я реализую метод наименьших квадратов и L2-регуляризацию через прямые матричные формулы — без использования `sklearn.linear_model`. Цель — разобраться, что именно происходит внутри линейных моделей, и показать на собственных глазах эффекты переобучения, неустойчивости плохо обусловленных матриц и пользу регуляризации.

> **Стек:** `numpy`, `pandas`, `matplotlib`, `seaborn`, `sympy`, `sklearn.model_selection.train_test_split` (только для разбиения выборки)

## Что внутри

### Часть 1. МНК и эффект переобучения
- Реализация МНК через формулу `a = (X^T X)^(-1) X^T y` на синтетических данных.
- Аппроксимация полиномами степеней от 1 до 10.
- Демонстрация переобучения и эффекта Рунге.
- Связь между интерполяционным многочленом Лагранжа и МНК на матрице Вандермонда полной степени.

### Часть 2. Многомерная регрессия на ценах квартир в Москве
- Базовая модель на исходных признаках с интерпретацией знаков коэффициентов.
- Диагностика через scatter «реальное vs предсказанное» и график остатков.
- Feature engineering: произведения признаков (`totsp*livesp`, `totsp*dist`) и логарифмы, обоснованные через корреляционный анализ (pairplot, heatmap).
- Сравнение качества базовой и усложнённой моделей.

### Часть 3. L2-регуляризация (гребневая регрессия)
- Реализация через `a = (X^T X + λI)^(-1) X^T y`.
- Подбор `λ` по отдельной валидационной выборке (с обоснованием почему не по тесту/трейну).
- Логарифмическая сетка `np.logspace(-10, 10, 50)`.
- Сравнение определителей `det(X^T X)` и `det(X^T X + λI)`, доказательство положительности.
- Теоретический разбор: решение задачи оптимизации, случай неполного ранга, почему не нужно регуляризовать свободный коэффициент.

### Часть 4. Онлайн-обучение
- Инкрементальное обновление накопленных матриц `X^T X` и `X^T y` через внешние произведения.
- Сложность одного шага `O(k²)`, не зависит от размера уже виденной выборки.
- Симуляция онлайн-обучения для функции `f(x) = 2x·sin(5x) + x² - 1`.

### Бонус: QR-разложение
Краткий разбор того, как QR-разложение позволяет численно стабильно решать МНК через `R·a = Q^T·y`.

Все данные лежат в папке `data/` рядом с ноутбуком, пути относительные.

## Файлы

- `linear_regression_from_scratch.ipynb` — основной ноутбук.
- `data/train.txt`, `data/test.txt` — синтетические данные для частей 1 и 3.
- `data/flats_moscow_mod.txt` — данные по квартирам Москвы для части 2.

- `requirements.txt` — версии библиотек.

## Что я узнал в ходе проекта

- Как из задачи минимизации `||Xa - y||²` получается нормальное уравнение и матричная формула МНК.
- Как именно проявляется переобучение и почему это связано с обусловленностью матрицы `X^T X`.
- Почему L2-регуляризация делает решение единственным даже при `rk X < k`, и почему она почти всегда улучшает обобщение.
- Как обновлять регрессионную модель на потоке данных без хранения всей выборки.
